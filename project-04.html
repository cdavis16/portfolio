Loveable

Sans Tabs

As a digital designer, I was constantly saving websites for inspiration. But when I needed to revisit one, I could rarely remember the name — only the visual in my head.

So I built a visual bookmark manager that lets users pin websites into collections with screenshot previews, turning scattered text links into a browsable, visual library of inspiration.

Claude Code

Portfolio Site

This entire portfolio was built using Claude Code. I used it as a development partner to structure components, refine layouts, and iterate quickly through ideas, while I directed the architecture, interaction, and visual decisions myself.

It became an experiment in AI-assisted building: accelerating execution while exercising and maintaining my own judgment.
